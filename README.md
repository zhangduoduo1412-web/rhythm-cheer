# 节奏应援 · 交互设计作品集

独立静态演示站，HTML / CSS / JavaScript，无构建步骤、无 API 密钥、无服务端依赖。

这是个人交互设计原型，非全民K歌官方产品；电视和手机在同一页面中模拟联动，不会建立真实跨设备连接。二维码为装饰占位图，演示不播放歌曲音频、不采集访问者信息。

## 体验

点击手机画面进入教程，再点击“模拟晃一下”开始。点击手机光圈或按数字 1 应援，其余玩家由原型模拟。每轮 40 秒，结束后可继续或结束应援。

默认入口为 `index.html`，`?result=1` 可直接查看结算演示。手机竖屏时可以上下滚动查看电视与手机。

IP 动画使用原始视频提取的透明 WebP 帧图集，由 Canvas 按原帧率播放，避免部分浏览器将 WebM 透明通道显示为黑底。原视频保留为源素材，导出工具为 `scripts/export-animation-atlases.py`（需要 Pillow 与 imageio-ffmpeg）。

## 发布和维护

GitHub Pages 从 main 分支根目录发布。保留仓库名称、账号名称和 Pages 设置，作品集中的地址就不必更换；更新文件并推送 main 即可更新页面。

本地预览：`python3 -m http.server 4174 --bind 127.0.0.1`。

平台及网络可能发生故障，不能承诺一年内零中断。建议保留 ZIP 备份，并在投递作品集前检查链接。若面向不同地区访问者，请在目标地区网络上验证可访问性。
